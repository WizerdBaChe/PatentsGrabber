# 人工驗收清單 — 2026-08-29 交付輪

這一輪所有機器檢查都綠了，但綠燈只證明**資料路徑與幾何**。
下面每一項都是機器看不到、必須由人在真實環境裡看過的東西。

**執行方式**：不需要讀過原始碼。照著做，看到的和「預期看到」不一樣就是失敗，
把那一項的編號和你實際看到的寫下來即可。

**用哪一份跑**：
- 打包版　`build\dist\PatentsGrabber\PatentsGrabber.exe`（雙擊）
- 原始碼版　`python run.py`

兩份的畫面一樣；只有第 1、2、13、14、15 項必須用**打包版**跑。

## A. 啟動與交付（打包版）

| # | 動作 | 預期看到 |
|---|---|---|
| 1 | 雙擊 `PatentsGrabber.exe` | 出現一個黑底文字視窗，寫出「資料夾」「設定檔」「網址」「記錄檔」四行路徑，然後**瀏覽器自己打開**。資料夾那一行是 `C:\Users\<你>\AppData\Local\PatentsGrabber`，**不是**程式所在的資料夾 |
| 2 | 不要關第一個視窗，**再雙擊一次** exe | 第二個視窗只印一行「已經有一份在執行（http://127.0.0.1:8000/），改開那一份。」然後自己關掉。**不能**出現第二個伺服器，也不能出現錯誤堆疊 |
| 3 | 回到第一個視窗，按右上角 X 關掉 | 網頁重新整理後連不上。這是正常的——視窗就是這個程式的開關 |

## B. 設定面板

| # | 動作 | 預期看到 |
|---|---|---|
| 4 | 按右上角「設定」 | 彈出面板。**Consumer Key / Consumer Secret 兩格是空的**，佔位字是「（留空＝不改動）」。上方灰框寫「已設定金鑰　Key 48 字元 · 結尾 …XXXX」之類——**只有長度和末四碼，不會出現完整金鑰** |
| 5 | 按「測試連線」 | 灰框先變成「正在向 EPO 換取 access token…　0.3 秒」**而且秒數會一直跳**；幾秒後變綠色並寫「金鑰有效」 |
| 6 | 在「OPS 位址」把網址改成 `https://evil.example`，按「儲存」 | 變成琥珀色，寫「OPS 位址只接受 epo.org 底下的主機。金鑰會以 HTTP Basic 標頭送到這個位址，所以它不能指向別的地方。」**位址欄的舊值不受影響** |
| 7 | 關掉面板再打開 | 兩個密碼欄又是空的，位址欄回到 `https://ops.epo.org/3.2` |
| 8 | 用記事本打開面板上寫的「設定檔」路徑 | 看得到 `OPS_CONSUMER_KEY=...`。**這是唯一一個有金鑰的地方**。把它關掉，不要改 |

## C. 圖式旋轉（核心新功能）

先查一件有圖的專利，例如在搜尋框輸入 `US6285999B1`。

| # | 動作 | 預期看到 |
|---|---|---|
| 9 | 按圖式下方的 **⟳** | 整張圖順時針轉 90°，而且**仍然完整在框內**、沒有被切掉、沒有壓到左邊的文字。下方出現「旋轉 90°」 |
| 10 | 連按 **⟳** 三次（總共四次） | 圖回到一開始的樣子，「旋轉 90°」的字消失 |
| 11 | 按 **⟲** 一次 | 和按一次 ⟳ 的方向**相反**，但畫面大小一樣 |
| 12 | 轉 90° 後，點一下圖 | 放大約兩倍。**捲軸能捲到圖的左上角**（往上、往左捲到底，看得到圖的角落，不會有捲不到的部分）。再點一次還原 |
| 13 | 轉 90° 後，按 **›** 換下一張 | 旋轉角度**保留**（同一件專利的圖頁方向通常一致），但放大**歸零** |
| 14 | 換查另一件專利 | 旋轉角度**歸零**（新文件從正的開始） |
| 15 | 按右上角「寬度」，再轉 90° | 圖的**寬**填滿右邊那一欄，上下可以捲。切回「頁面」整張又都看得到 |

## D. 壓力與異常路徑（比正常路徑更重要）

| # | 動作 | 預期看到 |
|---|---|---|
| 16 | 在圖上**連續快速按 ⟳ 十下** | 每一下都有反應，最後停在正確角度（10 mod 4 = 2，也就是上下顛倒），畫面不閃爍、不變形、不留白 |
| 17 | **連續快速按 › ‹ › ‹** 十幾下 | 頁碼跟得上，不會卡在「載入中」不動；EPO 模式下計時器每次都重新從 0 開始 |
| 18 | 把視窗從 FHD 螢幕**拖到另一個解析度的螢幕**（或縮放視窗寬度） | 圖跟著重新縮放，維持「整張看得到」；轉過 90° 的圖也一樣 |
| 19 | 切到別的分頁放著兩分鐘，再切回來 | 圖還在，沒有變成 0 大小或空白 |
| 20 | 查一件**沒有圖**的專利 | 右邊寫出**為什麼**沒有圖，並提供「改開原文件 PDF」的連結。**不會**出現破圖圖示，也不會有旋轉按鈕 |
| 21 | 拔掉網路，按「測試連線」 | 灰框變琥珀，寫出連不上的原因；秒數會跳；**不會永遠鎖住按鈕**（最多 60 秒後自己中止並說明是本機伺服器沒回話還是送不出去） |
| 22 | 查一件 EPO 才有圖的專利，翻到第 5 頁，**關掉再重開程式**，再翻到第 5 頁 | 第二次那一頁**幾乎瞬間**出現，而且頁碼列上第 5 頁底下有一條**綠色底線**（代表已在本機、不花配額） |
| 23 | 在設定面板按「清除金鑰」，確認後查一件新專利 | 右邊圖式區寫出「尚未設定 EPO OPS 金鑰。按右上角『設定』…」。Google Patents 有收錄的美國案**文字仍然讀得到**。之後記得把金鑰填回去 |
| 24 | 深色模式（Windows 設定 → 色彩 → 深色）下重開網頁 | 整個介面變深色，但**圖式區維持白底**（專利圖是黑線稿），文字讀得清楚 |
